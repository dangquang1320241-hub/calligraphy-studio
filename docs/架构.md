# calligraphy-studio 架构（D0）

目标：上传书法作品照片（+ 释文），按选定风格自动生成竖屏短视频。先服务家人，架构上保留对外开放的接缝。

## 1. 原则

1. **渲染器当黑盒复用**：12 个风格渲染器是既有资产，插件契约只约定 config schema + CLI 签名 + QC 挂钩，不重写渲染逻辑。
2. **作品档案是共享层**：每幅作品算一次（摆正/列框/字框/释文/读音），所有风格复用；人工确认成果（释文、读音）只有一份权威版本。
3. **状态全落盘**：档案、config、QC 结果都是文件；一个项目目录 = 一个独立产物，Web 化时把命令包成 HTTP 即可。Web 任务器（webapp/jobs.py）的任务状态同样落盘（`~/.calligraphy-studio/jobs/<jid>.json`），webapp 重启不丢。
4. **TTS 可替换**：core/tts.py 定义 Provider 接口，edge-tts 只是默认实现（商用前换 Azure/本地模型只动这一个文件）。

## 5. 插件契约（每风格一个包）

```
styles/<风格>/
   plugin.py     build_config(profile, project_dir, params) → (config.json, 生成报告)
   render*.py    渲染器（从模板迁入；仅允许改动：common 导入路径、TTS 走 core.tts）
   README.md     沿用原模板说明
meta（在 plugin.py 中声明）：NAME / NEEDS_TEXT / GRANULARITY（架构早稿的 extra_inputs 未实现，暂不要求）
```

- `build_config` 是自动化的核心：句切分（默认按标点逐短语，可用 `--sentences` 覆盖）、句↔列映射、region 计算、默认版式/音乐/响度参数。
- 渲染统一入口：`core.orchestrate make <风格> <作品图|--slug> [--text 释文.txt] [风格参数…]`
- QC 统一挂载：渲染器自带 ffprobe+联系表 → 附加 `core.qc.audio_align`（音画对位）→ 结果写入项目 `检查记录/`。

## 6. 人工确认点（3 个，都有可视化产物）

1. **列框确认**：`列框确认图.jpg`（列框+字框+逐字标注叠图）。列数/粘连/落款判定错误在此拦截。
2. **释文确认**：`释文.txt` + 对照图。草书识别永远是"AI 草稿 + 人审"，人工粘贴的释文同样过此关。
3. **成片验收**：联系表 + 关键帧 + 音画对位核验 json。

## 7. TTS 抽象

```python

PROVIDERS = {"edge": EdgeTTSProvider}      # 商用前注册 Azure/本地实现
```

## 7.5 LLM 接入（M1 后紧随，契约先定）

`core/llm.py` Provider 抽象（与 tts.py 对称），三个草稿生成器：

| 接入点 | 输出 | 红线 |
|---|---|---|
| draft_transcription(校正图) | 带置信度的释文草稿 + 与经典原文的反查验证 | 永远是草稿，必须过确认点 2 |
| annotate_pronunciation(释文) | 多音字读音表 + tts_text 替换建议 | 保留 MFCC-DTW 音频自检作二次验证 |
| draft_copy(profile) | 标题/分镜说明/发布文案/点评类风格点评初稿 | 事实句标"需核查"，点评标"示意" |

实现顺序：M1 收尾 → M1.5 ①②（价值最大）→ M2 时随点评类风格接 ③。无 API key 时降级为"导出图片包人工处理"。LLM 输出一律标 `draft` 写入档案，确认前不得进入渲染。


## 8. 里程碑（已与委托人确认的优先级）

- **M1** 朗读版全链路（本库核心跑通，三槐堂铭端到端验证）→ 当前
- M2 诗意叠化、一字一讲（句级家族；顺带补一字一讲的首次实渲）
- M3 章法解析、节奏卡点、临帖对比（字级；设计参照帖输入）
- M4 墨色呼吸、作品入画（B 族首选；验证档案层可选性）
- M5 慢揭幕、逐字特写、笔顺复现、书写路径（长尾；书写路径半自动描笔最后做）
- M6 Web 壳（仅当推广给外部作者前启动）

## 9. 明确不做（现阶段）

- 不统一 A/B 两族 config 约定；不自研狂草 OCR（用 LLM 视觉 + 人审）；不做 AI 超分/修补笔画（红线）。HEIC 输入已支持（pillow-heif 入口归一，iPhone/微信传图直接上传）。
- B 族渲染器 `--preview` 语义不一（bool 开关/int 帧数/未实现），stylekit.render_cmd_b 按各渲染器 argparse 声明适配透传；`layout_px` 双形态（kadian 落盘文件路径 / zhangfa 内嵌 dict）为已知约定漂移，暂不强行统一。
